# Census Data Analyzer · C#

C# census-data processing exercises with CSV loaders, JSON conversion, country-specific records and NUnit tests.

**CSHARP · DOTNET · CSV**

## What is included

| Location | Purpose |
| --- | --- |
| [Census Analyzer](Census%20Analyzer) | CSV factory, analysis and data classes |
| [Census Analyzer Test](Census%20Analyzer%20Test) | NUnit tests, Indian/US CSV data and JSON fixtures |
| [Census Analyzer.sln](Census%20Analyzer.sln) | Visual Studio solution |

## Getting started

The test project targets .NET Core 3.1. With a compatible SDK:

```bash
dotnet test "Census Analyzer.sln"
```

Open the solution in Visual Studio to inspect the tests and fixture paths.

## Project status

Historical learning project. Census fixtures are sample inputs and should not be treated as current population statistics.

Setup commands are documented from the repository structure; execution has not been revalidated as part of this presentation update.
